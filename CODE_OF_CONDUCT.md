# Community code of conduct

Be respectful, constructive, and welcoming. Discuss evidence and code rather
than attacking people. Harassment, discrimination, threats, sexual harassment,
doxxing, and publishing others' private information are unacceptable.

Maintainer JiuYang is responsible for moderation. When a repository issue tracker
is available, use it for non-sensitive conduct concerns or to request a private
contact channel; do not post private details or secrets. For a local distribution,
ask its supplier to connect you with the maintainer. No private reporting address
is currently configured.

Reports will be considered in context. Maintainer responses may include removing
content, requesting corrective action, or restricting participation. Apply these
standards in project discussions, reviews, and spaces representing the project.
