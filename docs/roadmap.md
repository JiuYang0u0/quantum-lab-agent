# Roadmap

0.1.0 is prepared locally and remains unreleased. These are candidate directions,
not committed delivery dates or implemented features:

1. Execute the authored Windows/Ubuntu CI on a hosted repository and document
   platform-specific installation results.
2. Broaden independently specified scientific evaluation cases, keeping model
   termination separate from task success and retaining failed evidence.
3. Establish a verified private reporting channel and release-maintenance policy
   before wider distribution.
4. Improve portable experiment manifests and operator recovery guidance while
   respecting uncertain external-job submission semantics.
5. Evaluate additional providers only with explicit budgets and reproducible
   settings; do not infer capability from `/models` listings.

Remote QPUs, arbitrary code tools, multi-user hosting, and automatic retries are
not part of this version. See [release readiness](release-readiness.md).
